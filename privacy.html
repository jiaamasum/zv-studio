Privacy Policy

Last updated: November 18, 2026

Who we are

ZV Studio operates an internal publishing application ("the App") that uploads and manages short gaming highlight videos on YouTube channels and a Facebook Page owned and operated by ZV Studio. The App is not offered to the public; it is used only by ZV Studio for its own accounts.

Google / YouTube data the App accesses

When an account owner signs in with Google, the App requests these YouTube API scopes:

  • youtube.upload — to upload videos to the signed-in channel;
  • youtube.readonly — to read the channel's name and the status, view, like and comment counts of videos the App uploaded;
  • youtube.force-ssl — to update the title, description or privacy setting of, or delete, videos on the channel.

The App also reads public live-chat messages of public YouTube live streams through the YouTube Data API to detect highlight moments. Usernames from live chat are never stored or shown in published videos.

How we use and store data

  • OAuth tokens are stored only on ZV Studio's own computer, protected by file permissions, and are used solely to perform the actions above on ZV Studio's own channels.
  • Video statistics (views, likes, comments) are stored locally to measure which videos perform best.
  • We do not sell, rent, share, or transfer Google user data to anyone, and we do not use it for advertising.
  • The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Facebook data

For the Facebook Page owned by ZV Studio, the App uses a Page access token to publish Reels and read their view and like counts. No other Facebook user data is collected.

YouTube API Services

The App uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at Google security settings (and in Facebook's Business Integrations settings). When access is revoked, the stored tokens stop working and are deleted from our computer; locally stored statistics are deleted on request.

Contact

Questions about this policy: contact ZV Studio through the "About" page of our YouTube channels.
